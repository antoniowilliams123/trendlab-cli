# TrendLab CLI — UX / UI audit against Claude Code (2026-10-05)

Method: a 40-point rubric covering the things people use every session. Each check was exercised
in the Textual TUI through the headless pilot at 132×40, 100×32, 120×36 and 80×24 (screenshots in
`docs/screenshots/`), in the plain REPL through a recording console, and in headless `-p` mode.
Error paths were driven with fake providers that raise the real exception classes. The Claude Code
column is the behaviour of the comparison product as used daily by the owner; it was not run side
by side on the same task, so it is a reference, not a measurement.

Scoring: ✓ at par or better · ◐ partial · ✗ missing. "Before" is the state at the start of the day's
audit; "After" is the state at commit `fix: retry streamed calls…` with 286 tests green.
